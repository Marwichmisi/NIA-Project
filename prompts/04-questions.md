# 04 — Questions (document importé)

Doctrine : `agent` (front-load : UNE salve groupée avec options, puis
implémenter sans s'arrêter), `planning` Phase 1 (spec + questions d'un coup).

1. Lire le document, lister l'exploitable (BOM partielle, contraintes, dims).
2. Lister le manquant pour un `document-plan` complet (cf. `01`).
3. Poser le tout EN UNE salve, options recommandées, fin de tour.
4. Réponses reçues → figer le document-plan → seulement alors générer.
5. En cours d'implémentation : ambiguïté = hypothèse raisonnable notée,
   jamais de nouvelle question bloquante sauf impasse réelle.
